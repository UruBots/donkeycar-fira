# FIRA Challenge Run Guide

This guide explains how to run the FIRA challenge mode in this repository.

## 1. What Is "Challenge" Here

- Challenge mode is enabled by `FIRA_CHALLENGE_ENABLED=True`.
- In competition profile, this is tied to `FIRA_COMPETITION_MODE=race`.
- Main config files:
  - `donkeycar/templates/cfg_simulator.py` (sim defaults, challenge enabled)
  - `donkeycar/templates/cfg_competition.py` (urban/race selector)
  - `donkeycar/templates/cfg_complete.py` (base defaults)

## 2. Prerequisites

1. Python environment ready (project dependencies installed).
2. Donkey simulator installed and reachable if you run in sim.
3. The car project has `manage.py` available (standard DonkeyCar car folder).

## 3. Run In Simulator (Fast Validation)

Use simulator config directly:

```bash
python manage.py drive --myconfig=donkeycar/templates/cfg_simulator.py
```

Expected behavior:

- Challenge policy active.
- Obstacle handling for cones/cars active.
- Safety signal estimator disabled in sim profile to avoid false hint contamination.

## 4. Run In Competition Race Mode

Use competition profile and set race mode:

```bash
export FIRA_COMPETITION_MODE=race
python manage.py drive --myconfig=donkeycar/templates/cfg_competition.py
```

Race mode profile sets:

- `FIRA_MODULAR=False`
- `FIRA_CHALLENGE_ENABLED=True`
- `FIRA_SAFETY_SIGNAL_ESTIMATOR=False`
- `AI_THROTTLE_MULT=0.65`

If you prefer fixed files without environment variables:

```bash
# Urban stage
python manage.py drive --myconfig=myconfig_competition_urban.py

# Race stage
python manage.py drive --myconfig=myconfig_competition_race.py
```

## 5. Useful Runtime Checks

Before running:

1. Confirm simulator is running if using sim.
2. Confirm selected config file is the intended one.
3. Confirm mode variable:

```bash
echo "$FIRA_COMPETITION_MODE"
```

For race mode it should print:

```text
race
```

Competition presets summary:

| Mode | Core stack | Checkpoint detector | Anti-DNF guard | Notes |
|---|---|---|---|---|
| `urban` | `FIRA_MODULAR=True`, `FIRA_CHALLENGE_ENABLED=False` | Disabled | Enabled globally | Enforces zebra + stop-line behavior |
| `race` | `FIRA_MODULAR=False`, `FIRA_CHALLENGE_ENABLED=True` | Enabled | Enabled with tighter cap | Runtime scheduler active |

## 6. Optional Tuning Knobs (Challenge)

Tune in `donkeycar/templates/cfg_simulator.py` or your custom config:

- `FIRA_CHALLENGE_STEERING_GAIN`
- `FIRA_CHALLENGE_MIN_THROTTLE_FACTOR`
- `FIRA_CHALLENGE_ENGAGE_SEVERITY`
- `FIRA_CHALLENGE_CLEAR_FRAMES`
- `FIRA_CHALLENGE_RECOVER_FRAMES`
- `FIRA_CHALLENGE_WARMUP_FRAMES`
- `FIRA_CHALLENGE_WARMUP_STEERING_GAIN`
- `FIRA_CHALLENGE_WARMUP_MAX_ABS_ANGLE`
- `FIRA_CHALLENGE_WARMUP_THROTTLE`

## 7. Recommended Verification

Run focused tests after config/code changes:

```bash
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python -m pytest -q \
  donkeycar/tests/test_fira_challenge.py \
  donkeycar/tests/test_fira_template_inputs.py \
  donkeycar/tests/test_template.py
```

If all pass, run a short simulator smoke to confirm movement and early obstacle behavior.

## 8. Offline Autotuning (P5)

Use session reports generated by `FiraCompetitionSessionReporter` to search safer/faster
challenge parameters offline.

Example run:

```bash
python scripts/fira_autotune.py \
  --reports-glob "data/**/fira_competition_report_*.json" \
  --output-dir data/fira_autotune \
  --trials 120 \
  --seed 42
```

Outputs:

- `fira_autotune_report_<timestamp>.json`: objective breakdown (baseline vs best, split scores, top trials).
- `fira_autotune_overrides_<timestamp>.py`: config override block ready to copy into your custom config.

Guardrails enforced by tuner:

- Parameter clipping to safe min/max bounds.
- Stability constraint `RECOVER_FRAMES >= CLEAR_FRAMES + 1`.
- Correction cap upper bound to avoid unstable steering spikes.
- Validation non-regression fallback: if best candidate underperforms baseline on validation split, baseline is kept.

## 9. Competition Readiness Additions

The project now includes four practical additions for competition readiness:

- Real checkpoint event detector (`FiraCheckpointDetector`) with `fira/checkpoint_event` output.
- Competition metrics consume real checkpoint events when available, and fallback to streak proxy otherwise.
- Imminent-collision anti-DNF throttle guard in `FiraChallengePart`.
- Official FIRA replay scoring utility and battery runner scripts.

Useful commands:

```bash
# Replay official SAR/SAUD/ST scoring from session reports
python scripts/fira_official_scoring_replay.py \
  --reports-glob "data/**/fira_competition_report_*.json" \
  --t-stage-race 120 --t-stage-urban 120 \
  --total-checkpoints-race 12 --total-checkpoints-urban 12

# Run repeatable competition battery (tests + scoring smoke)
python scripts/fira_competition_battery.py
```
